## Deliberately gated / remaining acceptance work

- **Native Codex TUI takeover:** disabled in capability discovery. The working Shell tool is a worktree shell. Seamless attachment to the same live Codex session needs its own version-specific compatibility and ownership tests.
- **Distribution:** the local macOS build is unsigned/not notarized and requires an existing Node 24+ and Codex installation. Signing/notarization needs distribution credentials. Windows/Linux are out of this release.
- **Memory inference:** optional Memory now proposes semantic notes from initial assessment and accepted work. These are model suggestions, not validated decisions; unapproved proposals never enter task context. The live six-turn smoke test covers Developer/Security/Verification; Memory provenance/exclusion is covered by fixtures, not a live quality benchmark.
- **Evaluation:** fixture results demonstrate system behaviour, not real-world model quality or reduced engineering effort. A representative live-model benchmark and usability testing remain.
- **Execution limits:** live Codex workers can survive a daemon restart; interactive shells and in-flight validation do not. A machine reboot interrupts execution and requires explicit resumption.
- **Dependency reconciliation:** verified file handoffs are conservative; symbolic-link changes and complicated multi-parent conflicts need manual review, not automatic merging.
- **Recovery audit:** tests exercise daemon detachment/reconnection and execution-process-group loss. Arbitrary power loss, disk-full journal writes, independently killed descendant processes and long-running soak tests still need a broader release audit.

No cloud sync, separate account system, scheduled unattended workflows, automatic source merges/pushes, recursive delegation or cross-vendor agent support were added.
